About

I'm Jackson Sibold. This site lists my public GitHub projects. Here is what they cover, based on their READMEs:

  • Python scheduling and delivery code, including DST-aware scheduling with zoneinfo, bounded retries with exponential backoff, and recovery from malformed state files (study-tip-sender).
  • Systems research on Windows PE loading, NT syscall dispatch, and compatibility conformance tooling alongside Linux's ABI. It is an incomplete research prototype, not a working compatibility layer (ntpers-research).
  • A full-stack TypeScript application using Next.js, Supabase, and Stripe integration routes. It is a source-code prototype, not a deployed service (autofair-showcase).

Several of these projects were developed with AI assistance, as their READMEs state.
